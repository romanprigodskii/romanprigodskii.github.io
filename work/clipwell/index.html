A small, native clipboard history for macOS and Windows. Free, MIT licensed, and one Homebrew command away.

Written twice

The same bar, the same cards, the same keys and the same history format, implemented natively on both platforms rather than once in Electron. No account and no subscription.

Installing it is one Homebrew command. That meant shipping a cask, a release pipeline and a product site alongside the app itself.

brew install --cask romanprigodskii/tap/clipwell

Passwords stay out

Content that a password manager marks as concealed or transient is never written to disk, so copied passwords do not end up in the history.
