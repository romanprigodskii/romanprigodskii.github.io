# prigodskii.dev

My personal site: the work, the research, and the record.

| | |
|---|---|
| **[/](https://prigodskii.dev/)** | the front page |
| **/work/&lt;project&gt;/** | one page per project |
| **[/research/](https://prigodskii.dev/research/)** | both papers in full, with their figures |
| **[/plain/](https://prigodskii.dev/plain/)** | one self-contained file, no JavaScript, prints to A4 |

Static HTML, CSS and vanilla JavaScript, served by nginx on my own server.
No framework and no build step for the pages; one small generator writes the
figures into them (below). The design is described in [DESIGN.md](DESIGN.md).

## Why the figures are real

Every series is read from [`assets/data/audit.json`](assets/data/audit.json),
generated by [`tools/build_data.py`](tools/build_data.py) from the numbers files
my papers were compiled against, or from
[`assets/data/boxing.json`](assets/data/boxing.json), copied from the Vertex
Boxing report with the section each number comes from.

```bash
python3 tools/build_data.py /path/to/paper > assets/data/audit.json
node tools/figures.mjs    # re-render the figures into the pages
```

## Layout

```
index.html                 the front page
work/<slug>/index.html     one page per project
research/index.html        both papers, and three school projects
plain/index.html           the printable version, self-contained
404.html
assets/css/site.css        tokens, type, every shared component and frame
assets/css/*.css           page-specific additions
assets/js/figures.js       figure renderers (browser and node)
assets/js/figures-*.js     page-specific renderers, loaded by tools/figures.mjs
assets/js/site.js          behaviour: reveals, the slide rule, the interactive figures
assets/js/*.js             page-specific behaviour
assets/data/               audit.json (generated), boxing.json (from the report)
assets/fonts/              Mona Sans, self-hosted (OFL)
assets/img/, assets/video/ posters, screenshots, and loops recorded from the products
papers/                    the PDFs
tools/figures.mjs          writes the figures into the pages
tools/build_data.py        regenerates audit.json
tools/og.html              the social card, screenshotted into assets/img/og.png
tools/deploy.sh            publishes HEAD to prigodskii.dev
server/                    the nginx container and its Traefik routing
```

With JavaScript off, or with reduced motion, every figure is shown in its
final state and the page is complete.

## Running it

```bash
python3 -m http.server 8777
```

`http.server` does not answer byte-range requests, which Safari needs to play
video at all and Chrome needs to seek; nginx on the server answers them.

## Deploying

```bash
tools/deploy.sh
```

It publishes the last commit, not the working tree, to `/opt/prigodskii-site`
on the server, where nginx serves it behind Traefik. GitHub Pages still builds
`main` at romanprigodskii.github.io; every page names prigodskii.dev as
canonical.
